# 鼓手節奏庫（Drum Chart）

一個給鼓手互相**傳承打法**的節奏庫。

「可以打什麼節奏」「這裡可以用什麼過門」——這些東西過去只能用形容詞講，或是打一次給對方看。
這個工具把它們變成一張張**點下去就聽得到**的卡片：分類、試聽、比較、傳給別人。

同一個 8 beat，很多鼓手手上只有一種打法。但它可以加 ghost note、可以切分大鼓、可以換成一拍一下、可以搬到 ride 上。
每張卡底下可以掛**變體**，兩張並排「輪流播」，差別一聽就知道——這是這個工具真正想解決的事。

順帶也解一個老問題：**主領和鼓手之間沒有共同語彙**。主領說「這裡熱一點」，鼓手不知道是加 ride 還是切 16 beat；
現在可以直接點兩張卡給他聽，讓他指一張。

把卡片排進一首歌的曲序是**附加功能**，不是主軸。

---

## 怎麼啟動

### 最快：直接開網址

線上版（GitHub Pages）：**https://dowiosamuelu.github.io/drum-chart/**

打開就能用，免安裝，內建 26 張卡（21 個節奏、5 個過門）當起手式。

### 本機跑（要改程式碼或離線時）

純前端的單檔網頁，但**不能直接雙擊開**（`file://` 會讓 YouTube 出錯，且讀不到 `samples/`），
用一個本機小伺服器：

```bash
git clone https://github.com/dowiosamuelu/drum-chart.git
cd drum-chart
python3 -m http.server 8777
```

瀏覽器開：**http://localhost:8777/index.html**

## 怎麼用

### 節奏庫（主畫面）

每張卡都把**譜直接畫在上面**——只畫有打的軌、只畫音符不畫格子，每拍一條淡線對齊，不用點開就能一眼掃過去。

1. **瀏覽**：首頁是**分類入口**——依「打法特徵」分區，每類先給你三張代表卡，
   按「看全部」展開該類全部（含變體）。右上角可以換分區依據（速度感 / 適用段落 / 打法特徵）。
2. **找卡**：左邊切「節奏 / 過門」，再用標籤篩選——**一開始篩選或搜尋，畫面就從分類入口切成平鋪的結果牆**。三組標籤——
   - **速度感**：快歌 / 中板 / 慢歌
   - **適用段落**：Intro/Outro / 主歌 / 副歌 / 橋段
   - **打法特徵**：8 beat / 16 beat / half-time / four on the floor（大鼓四分）/ 跑 ride / tom-tom / rimclick / 留白

   同一組裡選多個是「或」，跨組是「且」（選「慢歌 ＋ 副歌」＝ 兩個都要符合）。
3. **聽**：點卡片任何地方就是播放／停止，播放中整張卡會變色。
   **切分頁、改篩選都不會中斷播放**，可以一邊聽一邊找下一張。
   卡片右上的 ♥ 可以**收藏**，側欄勾「只看收藏」就只剩自己常用的那幾張（收藏存在你自己的瀏覽器裡）。
4. **配過門一起聽**：右上角「配過門」挑一張（一樣是看得到譜的卡片），之後點任何節奏卡都會用它一起播——
   第一小節純節奏，第二小節把過門疊上去。過門有音符的格子換成過門、空著的格子繼續走節奏，
   所以只佔最後一拍的過門就是「前三拍節奏、第四拍過門」，**過門佔幾拍由它自己決定**。
5. **比較**：變體卡（縮排在基礎卡底下）上有「對照」——
   兩張各兩小節交替、**共用同一個速度**，差別就聽得出來了。這是這個工具的重點。
6. **做變體**：滑到卡片上會出現操作按鈕，按「變體」，複製一份掛在同一張卡底下，改幾格。
7. **改譜**：按「編輯」開彈窗，七軌全開的大格子，點格子切換音符：
   - 七軌：Crash / Ride / Open HH / Hi-hat / Tom / Snare / Kick
   - **Snare** 連點輪：● 重音 → ○ ghost note（弱音）→ ◇ rimclick（cross-stick）→ 空白
   - **Tom** 連點輪：H → M → L（高/中/低）→ 空白
   - 其他軌：有 / 無



   彈窗裡也可以改名稱、標籤、備註、BPM，以及跟家族裡任一張「輪流播」。
8. **新增卡片**：「＋ 新增卡片」開一張空白的（會自動帶上你目前選的標籤）。

**名字是選填的。** 沒取名的卡會自己描述自己——基礎卡顯示標籤，變體顯示「跟父卡差在哪」
（「多了 ghost」「踩鈸 八分→十六分」「換成 ride」）。常用、常要跟人提到的卡再取名就好。
家族裡的變體也只畫跟父卡不同的那幾軌，差別一眼就看得到。

### 歌曲（附加）

排曲序、每段從節奏庫**挑一張節奏卡＋一張過門卡**。段落上一樣**直接畫出譜**，
「播放整段」會放「一小節節奏 ＋ 一小節（節奏＋過門）」循環。挑卡的彈窗裡也看得到每張候選卡的譜。

段落不能就地編格子——想要新打法就去節奏庫做一張。這樣每次排歌都在把庫養大。

可選配貼 YouTube 連結聽原曲 feel；現場曲速常和 YT 不同，影片只是參考、不是時間軸主軸。

目前固定 **4/4、16 格（十六分音符）**。因此標籤裡沒有 shuffle / 6-8——16 格打不出三連音，與其做個假的不如不做。

## 怎麼共享

資料分成三層：

- **官方庫**（`library.json`）：審核過的共用版本，跟著網站一起送到每個人手上。
  有新版時會跳一條橫幅問你要不要合併——**不會自動改動你的東西**。
  官方卡在本地是唯讀的；想改成自己的打法，按「做我自己的版本」複製一份。
  官方庫移除某張卡時，你這邊只會**封存**它，既有的歌不會壞。
- **個人庫**：你自己做的卡，存在瀏覽器裡，不會傳給任何人。這是實驗場。
- **收到的卡**：別人用分享連結傳給你的卡會先落在這裡，聽過再決定要不要收下。

日常的分享方式：

- **單張卡 → 網址**：卡片「編輯」裡按「複製分享連結」，用 LINE 貼給對方。
- **一首歌 → 檔案**：「匯出這首」會**連同用到的卡片一起打包**，對方匯入就能看＆聽。
- **我的庫 → 檔案**：「匯出我的庫」存成 `.json`，對方「匯入檔案」併進他的庫（重複的略過）。

### 想把一張卡放進官方庫

傳給維護者就好——複製分享連結，LINE 給他。他會在「收到的卡」裡聽過，覺得好就收進官方庫，
下次發佈時大家就都有了（目前大約兩三個月一輪）。

### 維護者：怎麼發佈新版官方庫

1. 側欄勾「管理模式」（純本機開關，不代表任何權限）
2. 要**加**的卡：在它的「編輯」裡勾「收進官方庫」
3. 要**拿掉**的官方卡：在它的「編輯」裡按「從官方庫移除」（只是封存，本機還留著，可以取消）
4. 按「匯出 library.json」，填一行更新說明
5. 把檔案覆蓋進 repo、commit、push

發佈之後你自己再同步一次，那些卡就會轉正成官方卡（跟其他人看到的一致）。
管理模式裡勾「顯示已封存的卡」可以找回被移除的卡。

版本號會自動加一，其他人下次打開就會看到更新提示。

## 已知限制 / 設計取捨

- **官方庫是一季一輪，不是即時同步**：提案要等維護者下次發佈才會進到大家手上。
  這是刻意的——5 個人的圈子不需要後端，而且「要 commit 才能進官方庫」本身就是審核機制。
- **個人資料存在瀏覽器 localStorage**：換瀏覽器／清快取會不見，重要的請記得匯出存檔。
- **第一次開啟需要連線**（要抓 `library.json` 和 `samples/`）；之後離線可以照用既有資料。
- 舊版（`drumchart_v3`，以歌曲為主的攻略表）的資料會自動搬過來：每個段落裡的節奏與過門會被抽成庫裡的卡片，
  段落改成引用它們。

## 技術

- `index.html`（程式）＋ `library.json`（官方庫內容），純前端無 build，個人資料存 localStorage（key `drumchart_v4`）。
- 測試：`node test.js`（123 條，不需要瀏覽器）。
- 資料模型：`patterns[]` 是第一級公民（卡片），`songs[].sections[]` 只存卡片 id（`grooveRef` / `fillRef`）。
  變體用 `parent` 表示，只做一層。
- 鼓譜資料格式：`pattern = { tempo, ri[], oh[], hh[], tm[], sn[], kk[] }`，每軌 16 格。
  `tm` 值 1/2/3 = 高/中/低 tom；`sn` 值 1/2 = 重音/ghost；其餘 0/1。
- 播放用 Web Audio 載入 `samples/` 的真鼓取樣 MP3 觸發；各鼓件音量在程式裡的 `GAINS` 微調。
  排程器 `playSeq()` 吃一串 `{pattern, bars}` 循環播放，A/B 比較和段落播放都走它。
- YouTube 用官方 IFrame API 嵌入（選配）。
